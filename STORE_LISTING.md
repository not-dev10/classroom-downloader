## Detailed Description

📥 Classroom Downloader — The easiest way to download Google Classroom materials

Tired of opening every attachment one by one? Classroom Downloader adds download buttons directly into Google Classroom so you can grab files instantly — individually, in bulk, or as a ZIP archive.

✨ KEY FEATURES

🔹 One-Click Downloads
A download icon appears beside every attachment. Click once to download. That's it.

🔹 Bulk Selection & Download
Check the files you want, then download them all at once. Select All, Deselect All, or pick specific files.

🔹 ZIP Archives
Package selected files or entire courses into a single ZIP file. Files are organized in folders: Course → Topic → Assignment → file.

🔹 Google Docs Export
Automatically exports Google Docs to PDF or DOCX, Sheets to XLSX or CSV, and Slides to PPTX or PDF. You choose the format in Settings.

🔹 Download All
One button to download every material from the current page. Progress tracking shows completed, failed, and pending files.

🔹 Right-Click Download
Right-click any file link → "Download with Classroom Downloader"

🔹 Smart Detection
Automatically detects new attachments as you scroll or navigate. Works with Google Classroom's dynamic page loading.

🔹 Download Manager
Queue system with configurable concurrent downloads. Failed downloads can be retried. Full download history.

⚙️ SETTINGS
• Choose export formats for Google Docs, Sheets, and Slides
• Set maximum concurrent downloads (1–5)
• Light, Dark, or System theme
• Preserve folder structure in downloads
• Skip already downloaded files

🔒 PRIVACY & SECURITY
• Uses your existing Google session — no extra login needed
• All processing happens locally in your browser
• No data is sent to external servers
• Only downloads files you already have access to
• Open source: https://github.com/not-dev10/classroom-downloader

📋 SUPPORTED FILES
Google Drive files, Google Docs, Google Sheets, Google Slides, PDFs, DOCX, XLSX, PPTX, images, ZIP files, and more.

⚠️ NOTE
Google Forms and YouTube links cannot be downloaded (they are interactive content, not files).
